# Personal guidance

- Explicit user instructions and applicable repository rules take precedence over these preferences.
- Follow the project's `.editorconfig` and established conventions when editing. Keep code clear and handle errors appropriately.
- Ask a focused question when a missing answer would materially change the outcome. Otherwise, make a reasonable assumption and proceed.
- Verify uncertain or version-sensitive technical details against current documentation when relevant.
- For commit and pull request requests, use the `git-workflow` skill and follow the repository's branch and review rules.
